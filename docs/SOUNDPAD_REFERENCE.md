# Soundpad 功能参考与本项目取舍

## 使用原则

LiveAudioBoard 只参考 Soundpad 已公开的产品工作流，不复制其代码、图标、文案、品牌或界面布局。
本项目继续保持“夜航玻璃拟态”视觉，并针对直播和 OBS 使用方式重新设计交互。

参考资料：

- [Soundpad 官方使用手册](https://www.leppsoft.com/soundpad/en/help/manual/)
- [Soundpad 官方录音说明](https://www.leppsoft.com/soundpad/en/help/manual/tutorial/recorder/)
- [Soundpad 官方播放模式说明](https://www.leppsoft.com/soundpad/en/help/manual/tutorial/playmode/)

## 借鉴功能与优先级

### 第一优先级：直播音效板核心

1. **单条音频全局快捷键**
   - 每条音频可以录入、修改和清除快捷键。
   - 检测重复、系统保留键和紧急停止键冲突。
   - 提供快捷键总览以及“一键临时禁用全部音效热键”。
   - 按键按下时触发，并加入防抖，避免按住后连续误播。

2. **播放模式**
   - 监听：只给主播试听。
   - 直播：只送入直播输出。
   - 同时：主播监听与直播输出同时播放。
   - 已完成独立监听/直播总线、逐音效路由与同设备去重；严格隔离直播时仍建议让直播总线
     选择 VB-CABLE/VoiceMeeter 等虚拟设备，并由 OBS 捕获该设备。

3. **音量一致性**
   - 对导入文件执行离线响度分析，保存建议增益，不修改原文件。
   - 以 EBU R128/LUFS 为基础，提供可配置目标响度和峰值保护。
   - 保留单条音频音量微调，避免直播中突然过响。
   - 所有声音叠加后经过主总线限幅，并显示实时峰值与增益衰减。（已完成首版）
   - 支持对尚无结果的资料库音频批量分析，允许取消并隔离单文件失败。（已完成首版）

4. **音效宫格与分类操作**
   - 支持拖放排序、拖入分类、分类随机播放快捷键。（排序与拖入分类已完成）
   - 增加宫格分页；同一个键位可随当前页切换对应音效。（固定分页已完成）

### 第二优先级：内容制作与可靠性

1. **录音器**
   - 支持麦克风和 Windows 回环录音。（默认设备已完成）
   - 默认输出 48 kHz 双声道，可选 WAV/M4A/MP3。（录音以 WAV 入库，三种格式可从编辑器导出）
   - 可限制最长录音时间、自动裁掉首尾静音，录制完成后直接加入资料库。（已完成）

2. **基础音频编辑器**
   - 非破坏式设置起止点、淡入淡出、音量和循环。（已完成）
   - 另存为新音效时再渲染文件，原始文件保持不变。（WAV/MP3/M4A 已完成）

3. **资料库备份与恢复**
   - 备份数据库、设置、快捷键和已托管媒体文件。
   - 自动生成轮换备份，并支持恢复前预览。

4. **文件管理体验**
   - 拖入文件或整个目录，递归导入音频。（已完成，首级子目录自动作为分类）
   - 文件缺失时明确标记，并提供重新定位和在资源管理器中查看。（缺失标记、自动找回与重新定位已完成）

## 暂不直接照搬的功能

- 不在 MVP 中开发或安装麦克风虚拟驱动；优先使用 OBS 应用音频捕获或用户已有虚拟音频设备。
- 自动按键、远程控制和文本转语音排在直播播放可靠性之后。
- 不默认允许快捷调整“观众端音量”；直播输出应通过响度目标和限幅保护保持稳定。

## 推荐开发顺序

1. 单条音频快捷键、冲突检查和快捷键总览。（已完成首版）
2. 资料库文件托管、SHA-256 去重和自动备份。（已完成）
3. 非破坏式起止点、淡入淡出、循环和响度分析。（已完成首版）
   - 建议增益由用户逐条启用，单曲峰值保护默认开启。
   - 0–5000 ms 播放冷却用于避免快捷键连按叠音。
4. 最终主混音总线限幅、实时电平反馈与批量响度分析。（已完成首版）
5. 文件缺失检测、重新定位与托管媒体恢复。（已完成首版）
6. 监听/直播双总线与播放模式。（已完成首版）
7. 回环录音、静音裁剪和基础编辑器。（已完成首版）
8. RSS/Atom 音频附件浏览与可恢复下载。（已完成首版）
