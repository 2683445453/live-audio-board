# Security Policy

## Supported versions

Security fixes are provided for the latest published `0.22.x` release line. Development branches may
change without compatibility guarantees.

## Reporting a vulnerability

Do not disclose an unpatched vulnerability in a public issue. Use the repository's
[private vulnerability reporting page](https://github.com/2683445453/live-audio-board/security/advisories/new)
and include:

- affected version and Windows version;
- clear reproduction steps or proof of concept;
- impact on local files, credentials, downloads, audio routing or update packages;
- any known mitigations.

The project does not intentionally collect telemetry. Reports involving Freesound credentials should
never include a real Client Secret, authorization code, access token or `freesound.auth` file.
